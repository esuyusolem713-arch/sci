# sci｜NMIBC 病理图像 AI 开题工作区

用于逐步整理非肌层浸润性膀胱癌（NMIBC）的研究问题、文献、公开数据、操作步骤和阶段性结果。当前处于**可行性核查与开题准备阶段**。

## 现在先完成什么

首个里程碑：核查一个候选数据集，实际打开至少一张 H&E 图像，说明它能否与目标标签对应，并形成一页有来源、有局限说明的开题材料。若无法配对，也如实记录缺口。

目前没有已确认的可用配对样本量、模型训练结果或预后分析结果。仓库骨架建立不代表研究基础已经完成。

## 从这里开始

1. 打开 [任务清单](TASKS.md)，从 T01 开始。
2. 在 [数据登记表](data/README.md) 记录来源、权限、研究人群和配对情况。
3. 按 [最小操作流程](analysis/README.md) 完成图像查看与标签核对。
4. 将真实产出登记到 [结果索引](results/README.md)，再用于开题 PPT。

## 当前科学问题状态

工作问题是：**在可获得的 NMIBC 数据中，H&E 形态能否反映某个已有分子标签；该标签与临床结局的关系是否值得进一步研究？**

这只是待收敛的问题框架。分子标签、研究人群、主要结局均未定稿，详见 [问题草案](docs/research-question.md)。先核查数据，再决定是否建模；图像能打开不等于标签可配对，标签可配对也不等于有复发随访。

## 初学者如何维护

无需安装 Python、Git 或训练环境。在 GitHub 打开文件，点击铅笔按钮编辑，预览后提交；用简短提交说明，例如“补充 D01 的标签来源”。需要新增文字文件时，用 Add file → Create new file，文件名可包含目录路径。

完成任务就在 TASKS 中把 `[ ]` 改为 `[x]`，并附上仓库内的证据链接。只有计划时保持未勾选。表格中的“待填写”是占位，不能作为真实数据引用。

## 公开仓库的文件边界

这里只保存允许公开的研究笔记、来源链接和小型衍生结果。原始 WSI、受限临床数据、可识别患者信息、账号凭据和未获公开授权的材料保留在获批存储位置；登记访问方式即可。公开可下载也不自动意味着可以再次分发。上传截图前检查切片标签、个人信息和来源使用条款；文献优先保存链接。

当前不配置依赖、训练代码或自动化流水线。未来确有需要时再逐项增加。
