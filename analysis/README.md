# 开题前最小操作流程

目标：用一个真实数据源完成可追溯的展示。当前没有训练或分析结果；下面是待执行步骤。无需先安装编程环境。

## 1. 核查入口

在 [数据表](../data/README.md) 填 D01，确认图像、标签和权限。只需先检查一个数据源。

产出：官方入口、核查日期、缺失项目。

## 2. 打开一张图

优先用数据库提供的网页查看器；否则根据文件格式选择本地查看工具。先获取一个允许访问的示例，避免直接下载整个队列。

记录文件标识、使用工具、操作步骤和实际结果。保存截图时保留有用尺度信息，并核对切片标签及公开权限；无法确认倍率/尺度时写“未知”。

产出：可公开截图或官方查看链接。截图只能证明能看到图像。

## 3. 找到一个标签并核对配对

从官方说明找到字段定义、数据版本和配对规则。确认是同一患者、哪个样本、何时取材，避免把患者级标签说成局部区域测量。

产出：数据表中的一条真实配对记录，或明确的失败原因。只有测序得到的患者级标签，不能作为每个图像区域都有真实空间标签的证据。

## 4. 整理一页材料

按实际证据选择出口：

- **图像与标签可以配对**：一张图像示例 + 标签定义 + 配对依据 + 仍缺少的信息。
- **尚不能配对**：官方图像示例/入口 + 数据资源核查表 + 访问或配对缺口 + 下一步获取方案。

图注应写清“数据可行性展示”，并列出来源与核查日期。不能把示例、预期路线或文献中的结果写成本研究的结果。

产出：一页材料或图表文件，登记到 [结果索引](../results/README.md)。

## 5. 再决定是否进入建模

先核实可用独立患者数、类别分布和标签质量。如果以后训练模型，必须按患者划分数据，防止同一患者的切片/patch 跨训练与验证集。复发分析另需明确结局和随访；仅有图像与分子标签时不能完成这一步。

## 每次操作的最少记录

- 日期、对应 Dxx/Lxx：
- 工具与版本（能查到时）：
- 做了什么：
- 输入来源/版本：
- 输出文件或链接：
- 遇到的限制与下一步：

可把该记录写在对应结果条目中，暂不新增日志系统。
