## 每个数据源至少检查

- 官方数据入口和相关文献；保留来源链接与核查日期。
- 是否确为目标 NMIBC 人群，有无治疗信息；不能仅凭“膀胱癌”判断。
- 图像类型（诊断 H&E、冰冻切片、其他）、格式、实际可打开性。
- 标签如何获得：RNA 测序、蛋白检测、既有分类器，还是其他方式。
- 图像和标签如何匹配；患者、样本、切片层级有无跨层级映射。
- 是否来自相同取材时点；同一患者的多张切片如何关联。
- 区分数据库总人数、目标亚组人数、真正具有所需配对信息的人数。
- 若研究复发：复发定义、观察起点、事件、末次随访和治疗背景能否确认。
